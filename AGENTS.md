## Project

Vue 3 + Vite + Storybook 10 component library mirroring the **"❖ Comfy UI"**
Figma design system (fileKey `60wkPriIjI9zjyAKOq3dja`).

## The one rule you must not break

**Everything is token-driven.** Never hardcode a hex / rgba / px color in component
CSS — every color, spacing, radius and type value must come from the design-token
system (`src/foundations/tokens.css`, generated by `scripts/gen-tokens.mjs`).
Components use the **semantic layer only** (`var(--bg-brand-primary)`,
`var(--bg-brand-primary-hover)`, `var(--text-secondary)`) — it has Light + Dark values,
primitives don't; `currentColor` for icons. Regenerate tokens with `pnpm gen:tokens`; `pnpm check:tokens` verifies them against the committed
Figma snapshot (CI) — refresh steps in [`/context/figma-token-mapping.md`](./context/figma-token-mapping.md).

Details and rationale: [`/context/token-driven-components.md`](./context/token-driven-components.md)
and [`/context/figma-design-system-source.md`](./context/figma-design-system-source.md).

## Working style

- With Storybook running, its MCP server (`http://localhost:6006/mcp`) lists stories per
  component and runs story tests — see [`/context/storybook-mcp.md`](./context/storybook-mcp.md).

- Verify changes live in Storybook (`:6006`) using text-based checks; do not post
  screenshot images into chat — see [`/context/no-screenshots-in-chat.md`](./context/no-screenshots-in-chat.md).

## Keeping context alive

When you learn a durable fact, rule, or preference, write it as a note in
`/context/` (frontmatter + `[[links]]`) and add a line to `/context/README.md`.
Do not stash it in a single tool's private memory.
