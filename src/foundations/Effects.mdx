# Effects

Shadow and blur effect styles, synced from the Figma design system
([Foundations / Effect styles](https://www.figma.com/design/60wkPriIjI9zjyAKOq3dja/?node-id=1030-33573)).

## Elevations

Drop-shadow styles for the light theme, from subtle (`E50`) to prominent (`E500`).
Shadow colors reference the `alpha-black` scale.

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 56, padding: '32px 8px' }}>
  {elevations.map((e) => (
    <div key={e.name} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: 12 }}>
      <div
        style={{
          width: 128,
          height: 128,
          borderRadius: 12,
          background: '#ffffff',
          boxShadow: e.boxShadow,
        }}
      />
      <div style={{ textAlign: 'center' }}>
        <div style={{ fontWeight: 600, fontSize: 14 }}>{e.name}</div>
        <div style={{ fontSize: 12, color: '#737373' }}>{e.token}</div>
      </div>
    </div>
  ))}
</div>

## Blur

Background-blur styles (`backdrop-filter`) used for frosted-glass surfaces. Figma
stores the blur radius at 2× the CSS value, so `B100` (radius 8) renders as
`blur(4px)` on the web. Each style also carries a subtle noise overlay in Figma.

Each swatch below shows a white-tinted (`bg-blur-white`) and a dark-tinted
(`bg-blur-dark`) glass surface over a colorful background.

<div style={{ display: 'flex', flexWrap: 'wrap', gap: 24, padding: '32px 8px' }}>
  {blurs.map((b) => (
    <div key={b.name} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: 12 }}>
      <div
        style={{
          position: 'relative',
          width: 200,
          height: 160,
          borderRadius: 16,
          overflow: 'hidden',
          background:
            'repeating-linear-gradient(45deg, #2abd13 0 24px, #fc5e0f 24px 48px, #3699f4 48px 72px, #8b5cf6 72px 96px)',
        }}
      >
        <div style={{ position: 'absolute', inset: 0, display: 'flex' }}>
          <div
            style={{
              flex: 1,
              backdropFilter: b.backdropFilter,
              WebkitBackdropFilter: b.backdropFilter,
              background: blurSurfaces['bg-blur-white'],
            }}
          />
          <div
            style={{
              flex: 1,
              backdropFilter: b.backdropFilter,
              WebkitBackdropFilter: b.backdropFilter,
              background: blurSurfaces['bg-blur-dark'],
            }}
          />
        </div>
      </div>
      <div style={{ textAlign: 'center' }}>
        <div style={{ fontWeight: 600, fontSize: 14 }}>{b.name}</div>
        <div style={{ fontSize: 12, color: '#737373' }}>{b.token} · {b.backdropFilter}</div>
      </div>
    </div>
  ))}
</div>
