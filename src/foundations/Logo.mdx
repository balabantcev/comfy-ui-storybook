# Logo

The COMFY brand logo, synced from the Figma design system
([Logos](https://www.figma.com/design/60wkPriIjI9zjyAKOq3dja/?node-id=1083-118533)).

The bright green pill conveys freshness and a modern, technological approach; the
white wordmark reads cleanly and clearly. The orange element adds dynamism and
symbolises pressing the start button — both new ideas and innovative solutions.

export const Cell = ({ entry, dark }) => (
  <div style={{ display: 'flex', flexDirection: 'column', gap: 8 }}>

## Wordmark

The full logo. Use **green** on light surfaces, **white** on dark or photographic
backgrounds, and **mono** where a single ink is required.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: 16, marginTop: 16 }}>
  {logos.filter((l) => l.kind === 'wordmark').map((l) => (
    <Cell key={l.name} entry={l} dark={l.variant === 'white'} />
  ))}
</div>

## Mark

The icon mark for compact placements (favicons, avatars, app icons). **Modern**
is the dimensional gradient treatment; **default** is the flat outline.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: 16, marginTop: 16 }}>
  {logos.filter((l) => l.kind === 'mark').map((l) => (
    <Cell key={l.name} entry={l} />
  ))}
</div>

## Usage

A `<Logo>` component renders any variant and scales to the given height:

```vue
<Logo kind="wordmark" variant="green" :height="33" />
<Logo kind="wordmark" variant="white" :height="33" />
<Logo kind="mark" variant="modern" :height="40" />
```
